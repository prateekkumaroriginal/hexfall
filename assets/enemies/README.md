# Orc Blender asset

The game loads `../../public/models/orc-rigged.glb`. Its editable rig, baked animation clips, and Blink/JawOpen/BrowTense facial shape keys are in `orc-rig.blend`.

`../../public/models/orc-source.glb` is the static input to `scripts/rig-orc.py`. Keep it so the current rig can be rebuilt. Import and rig export commands are documented in [creature art inspection](../../docs/creature-art.md#rigged-game-model).

The earlier five-joint model and its export pipeline have been removed. Numbered Blender backup files are local and ignored by Git.
