# Mountain rock textures

The color, OpenGL normal, and combined ambient occlusion/roughness/metallic maps
come from [Marble Cliff 03](https://polyhaven.com/a/marble_cliff_03) by Amal Kumar,
published by Poly Haven under [CC0](https://polyhaven.com/license).

These are the 2048 × 2048 maps, recompressed as JPEG for the browser build.
The normal map remains in OpenGL orientation and linear color space. The surface
map stores ambient occlusion in red and roughness in green. The metallic channel
is unused because the rock is nonmetallic.
